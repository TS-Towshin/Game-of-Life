## John Conway's Game of Life simulation.
This is a prime example of Cellular Automata. The grid is full of dead or alive cells.<br>
<br>The rules are simple:
<ol>
  <li>Each alive cell with one or more neighbors dies.</li>
  <li>Each alive cell with four or more neighbors dies.</li>
  <li>Each alive cell with two or three neighbors survive.</li>
  <li>Each dead cell with three neighbors becomes populated.</li>
</ol>
With just these four rules, infinitely many combinations can be generated.

## Installation
If your are running the simulator for the first time, execute run.py and press y to install the dependancies. Next time you can either execute run.py or engine.py to run the simulation.

## How to play
<ul>
  <li>Left click anywhere to toggle cell.</li>
  <li>Press Enter/Return to auto simulate.</li>
  <li>Press Space to simulate next generation.</li>
  <li>Press H to toggle highlighter.</li>
  <li>Press Esc to reset the grid.</li>
</ul>
